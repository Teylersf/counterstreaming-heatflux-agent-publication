# Input data and retrieval

The published input decks, derived profile, data dictionary, provenance and
license attribution are at [`../../data/`](../../data/). The verified selected
member downloader is [`../../experiments/fetch_data.py`](../../experiments/fetch_data.py).
See [`../README.md`](../README.md) for commands. The raw HDF5 cache is not shipped;
the fetch script retrieves only the pinned selected members when needed.
